## 🚀 How to Enable GitHub Pages (Vite React Build)

If your GitHub Pages is currently showing a placeholder or raw README, it is because GitHub Pages is set to read from the branch root without running the Vite build.

To show the live React website:

1. Open your repository on GitHub.
2. Click **Settings** (top tab) -> **Pages** (in the left sidebar).
3. Under **Build and deployment** -> **Source**:
   - Change from **"Deploy from a branch"** to **"GitHub Actions"**.
4. That's it! GitHub will automatically trigger the included workflow (`.github/workflows/deploy.yml`), run `npm run build`, and publish your real website to your GitHub Pages URL with 100% working styles, images, and WhatsApp/Call buttons.

